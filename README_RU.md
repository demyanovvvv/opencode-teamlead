# OpenCode TeamLead v2.1.2

[English README](README.md) · [Подробная инструкция по установке](INSTALL_RU.md) · [История изменений](CHANGELOG.md)

TeamLead помогает получать проверенные изменения в OpenCode без лишних исполнителей и затрат на модели. В зависимости от сложности задачи он выбирает режим **Direct**, **Managed** или **Team**, запускает изолированных исполнителей и проводит проверки перед интеграцией изменений.

В версии 2.1.2 доступны английская и русская локализации интерфейса TeamLead и установщика. При интерактивной установке язык можно выбрать в меню; для скриптов доступны параметры `--language en|ru` и `-Language en|ru`. При обновлении существующие настройки проекта сохраняются.

## Возможности

- Индикатор рядом с полем ввода показывает текущую фазу, режим, прогресс задач и число активных исполнителей.
- Меню **TeamLead** в Ctrl+P позволяет открыть статус и историю, запланировать или запустить задачу, продолжить выполнение, посмотреть модели, настройки и диагностику.
- Выбор моделей учитывает доступность, возможности, контекст, ограничения бюджета и локальные результаты, а не название модели.
- Исполнители работают с ограниченной областью записи; изменения проверяются и интегрируются из Git worktree.
- Настройки и история запусков изолированы по проектам даже при глобальной установке.

## Совместимость

OpenCode `>=1.18.30 <2.0.0`. Индикатор и меню требуют поддержки TUI-плагинов в используемой версии OpenCode; slash-команды и серверные инструменты остаются доступными без неё.

## Установка

Распакуйте архив релиза и выполните один из вариантов:

```bash
./install.sh --scope local --project /path/to/project
./install.sh --scope global
```

```powershell
.\install.ps1 -InstallScope Local -Project C:\путь\к\проекту
.\install.ps1 -InstallScope Global
.\install.ps1 -InstallScope Local -Language ru -Project C:\путь\к\проекту
```

Перезапустите OpenCode и откройте раздел **TeamLead** в Ctrl+P или выполните `/lead-doctor`. Интерактивный выбор области установки также доступен при запуске установщика без параметров. Подробности и обновление с предыдущих версий: [INSTALL_RU.md](INSTALL_RU.md).
Для обновления повторите команду установки: код и агенты обновятся, настройки проекта и выбранный язык сохранятся.

Для полного удаления закройте OpenCode и выполните:

```powershell
.\install.ps1 -InstallScope Local -Project C:\путь\к\проекту -Uninstall
.\install.ps1 -InstallScope Global -Uninstall
```

```bash
./install.sh --scope local --project /path/to/project --uninstall
./install.sh --scope global --uninstall
```

Удаляются файлы, команды, агенты, настройки и история TeamLead, а также регистрация в TUI. Пользовательские файлы OpenCode сохраняются. Глобальное удаление очищает глобальную установку; для удаления локальных настроек и истории выполните локальное удаление в каждом нужном проекте.

## Первый запуск

```text
/lead-doctor
/lead-models
/lead-plan Исправь ошибку авторизации и добавь регрессионный тест
/lead Исправь ошибку авторизации и добавь регрессионный тест
```

Другие команды: `/lead-status`, `/lead-resume`, `/lead-settings`. Полное описание архитектуры, ограничений и тестирования см. в [английском README](README.md) и папке [docs](docs/).
